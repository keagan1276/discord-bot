# Deadside Factions image selector + Discord search + embed publishing

Replace:
- bot.py
- dashboard/app.py
- dashboard/templates/deadside/factions.html
- dashboard/static/css/dashboard-system.css

Add this whole folder:
- dashboard/static/images/deadside_flags/

Features:
- 30 image flags cropped from the supplied Deadside flag sheet
- Visual image-only flag selector
- Search Discord names for faction leader
- Search and add faction members as removable chips
- Select a Discord channel for faction details
- Save and publish a faction embed
- Existing embed is edited instead of duplicated
